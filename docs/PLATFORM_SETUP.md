# Platform setup

Platform runners and generated bridge files are intentionally generated by the official tooling,
not maintained by hand. From the repository root, after installing Flutter, Rust and
`flutter_rust_bridge_codegen` 2.13.0:

```sh
flutter create --platforms=android,ios --org com.waanne .
flutter_rust_bridge_codegen integrate --integration-backend native-assets
flutter_rust_bridge_codegen generate
```

Then add the following platform permissions before building.

## Android

In `android/app/src/main/AndroidManifest.xml`, above `<application>`:

```xml
<uses-permission android:name="android.permission.RECORD_AUDIO" />
<uses-feature android:name="android.hardware.microphone" android:required="true" />
```

Use Android min SDK 24 or newer. Start with `arm64-v8a` only while benchmarking the native models.

## iOS

In `ios/Runner/Info.plist`:

```xml
<key>NSMicrophoneUsageDescription</key>
<string>LAED cần microphone để nhận câu hỏi bằng giọng nói.</string>
```

Use iOS 13 or newer. Model weights belong in application support storage, not in source control or
an asset bundle. The installer must verify free space and SHA-256 before an atomic activation.
